    PERFORMANCE ENGINEERING (PE) AUDIT DASHBOARD - QUICKSTART

HOW TO RUN:
-------------------------------------------------------------------
1. Simply double-click "start.bat" (or "START_DASHBOARD.bat") located 
   right in this root folder.

2. That's it! The launcher will automatically:
   - Verify Python and Node.js prerequisites.
   - Install dependencies if running for the first time.
   - Start the FastAPI Audit API on http://127.0.0.1:8765
   - Start the React MFE Dashboard on http://127.0.0.1:3000
   - Automatically open your default browser to http://127.0.0.1:3000

PREREQUISITES (IF NOT ALREADY INSTALLED):
-------------------------------------------------------------------
- Python 3.11+ (Download from https://www.python.org/ - make sure to check "Add Python to PATH")
- Node.js 18+ LTS (Download from https://nodejs.org/)

FEATURES INCLUDED:
-------------------------------------------------------------------
- 4 Core PE Pillars:
    * Data Dynamics (SOW vs DB data volume)
    * Batch Analytics (Control-M execution & SLA compliance)
    * Infrastructure & Resource Health (Azure Monitor CPU/Memory)
    * UI & Performance Benchmarking
- Unified Findings Command Center & Hero Strip
- Interactive Highcharts: Waterfall, Radar, and Severity Distribution Donut
- Deep-dive telemetry breakdowns and PDF/HTML report exports
