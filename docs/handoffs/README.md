```markdown

- `command` → output

### What shipped

### Proven vs unverified
- Proven: evidence actually exercised.
- Unverified: skipped browser, deployment, or external-system checks.

### Remaining work
- Item

### Durable lesson
- Only a repeatable, repository-specific rule.
```
