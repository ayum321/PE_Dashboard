# Antigravity Agent Rules

## Execution Policy
- **Autonomous Execution:** Execute all terminal commands, code changes, builds, unit tests, and git operations immediately and proactively.
- **No Confirmation Prompts:** Do NOT ask the user for approval or permission before executing commands or making edits.
- **No Blocking Feedback:** Do NOT pause or block on implementation plan approval gates or question prompts. Directly execute required actions and verify results.
